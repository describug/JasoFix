# JasoFix

맥에서 만든 한글 파일명이 윈도우에서 `ㅇㅓㅂㅁㅜ_PAX`처럼 조각나 보이는 **자소 분리 문제**를 해결하는 macOS 앱입니다.

## 왜 이런 문제가 생기나요?

macOS는 한글 파일명을 **자소 분리형(NFD)** 유니코드로 저장하고, 윈도우는 **조합형(NFC)** 을 사용합니다. 그래서 원격 데스크톱 폴더 공유, 클라우드 동기화, USB 등으로 맥의 파일을 윈도우에서 열면 파일명이 깨져 보입니다.

JasoFix는 선택한 폴더 안의 모든 파일/폴더 이름을 조합형(NFC)으로 바꿔줍니다. 맥에서는 두 형식이 똑같이 보이고 동작하므로 부작용이 없습니다.

## 기능

- **폴더 선택** — 자소 분리를 해결할 폴더를 여러 개 등록할 수 있습니다
- **즉시 실행** — 버튼 하나로 선택된 폴더와 하위 전체를 즉시 변환합니다
- **백그라운드 자동 실행** — 설정한 주기(기본 5분)마다 자동으로 변환합니다. macOS 내장 launchd에 등록되는 방식이라 상주 프로그램이 없고, 체크를 해제하면 등록도 해제됩니다
- 자동 실행 기록은 `~/Library/Logs/JasoFix.log`에 남습니다

## 빌드 방법

Xcode 프로젝트 없이 스크립트 하나로 빌드합니다. (Xcode Command Line Tools 필요)

```bash
./build.sh
cp -R build/JasoFix.app /Applications/
```

macOS 13(Ventura) 이상.

## 동작 원리

- 폴더 트리를 하위 항목부터 순회하며, 이름의 UTF-8 바이트가 NFC 정규화 결과와 다른 항목만 POSIX `rename()`으로 이름을 바꿉니다
- Swift `String` 비교와 `FileManager` 경로 변환은 유니코드 정규화를 다시 적용해버리는 함정이 있어, 바이트 단위 비교와 C 문자열 rename을 사용합니다
- 백그라운드 모드(`JasoFix --background-run`)는 UI 없이 변환만 수행하고 종료합니다
